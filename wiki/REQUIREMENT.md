# 요구사항 요약

원본 계획: [PLAN.md](PLAN.md) (v1.0, 2026-08-22 승인). 이 문서는 **현재 구현 기준 합의 사항**의 요약본이다. 2026-08-23 코드 기준으로 동기화함.

## 1. 제품 목표

- 탑다운 3D 좀비 아포칼립스 **파밍 로그라이크** "DEAD BLOCK" (v0.1.0).
- 전투보다 "무엇을 털고 어떻게 나올 것인가"의 판단(리스크/리턴)이 중심인 파밍 루프를 제공한다.
- 죽으면 런 수집물은 소실, 메타 재화(스크랩)만 보존되는 반복 동기를 만든다.

## 2. 사용자

- 로그라이크·서바이벌 장르를 즐기는 PC 단일 플레이 유저.
- 멀티플레이·보스·날씨는 범위에서 보류(파밍 루프 검증이 1차 관문).

## 3. 주요 기능 (구현 수준: ●완료 / ○예정)

| 기능 | 현재 합의 사항 |
|---|---|
| ● 핵심 루프 | 진입(main_menu→stage1) → 파밍 → 좀비 조우·전투 → 인벤 관리 → (M4~)탈출 → 메타 성장 |
| ● 파밍 | `Interactable` 컨테이너 홀드 E 수색(기본 `search_time` 2.0초, 이동·섭취 중 취소), 완료 시 소음 반경 8m(priority 1). 컨테이너 런당 1회, 초과 수집분은 바닥 드롭. **줍기 판정은 수색보다 우선** — 수색 범위와 아이템 드롭이 겹치면 아이템부터 획득 |
| ● 좀비 AI | FSM(IDLE/WANDER/CHASE/ATTACK/DEAD), 인지 주기 0.2초. 시야 10m·FOV 100° + 2m 이내 무조건 인지, LOS 레이캐스트(world 레이어). 어그로 해제 = 1.6×시야. 공격 선딜 0.25초 / 쿨 1.1초 / 피해 10. **호드 단위 스폰**: 모든 스폰은 1~4마리 호드(가중치 [45,52,2,1] → 1~2마리 약 97%, 3~4마리 극히 희소 약 3%), 같은 지점 반경 2.2m 내 군집 스폰. 간격 4초 / 플레이어 반경 14~24m / 동시 상한 60마리. **격파 시 코인 1개 드롭**, 접촉 수집 → 별도 점수 누적(HUD 좌상단, 런 시작/재시작 시 초기화) |
| ● 근접 전투 | 맨손: 피해 25 / 사거리 1.8m / 90°. 무기는 `ItemData` 스탯 사용(예: 야구배트 30 dmg / 2.6m / 100° / 2타점 / 내구 25 / 쿨 0.75). 내구도는 명중 시에만 소모. 공격 시 소음 반경 5m |
| ● 생존 스탯 | HP 100 / 스테미나 100 / **허기+갈증 2종**(감소 속도: 허기 300초, 갈증 210초). 허기 0 시 스테미나 회복 절반, 허기·갈증 0 지속 시 2초마다 HP -2. 피격 무적 0.45초 + 넉백 |
| ● 소모품 섭취 | E키 홀드로 섭취. **시작 시에만** 수색 우선(수색 대상 근처에선 시작 불가). 일단 시작하면 수색 범위에 들어가도 끝까지 완료. `consume_time` 경과 후 효과 적용. 섭취 중 이동 속도 55% 감소, 조준·질주 불가. **모든 소모품은 1회용**(사용 시 1개 제거, 남은 개수만큼 반복 가능) |
| ● 인벤토리 | 슬롯 20칸 + **무게 상한 40**, 스택형(`max_stack`). 퀵슬롯 **8칸**(1~8 키 / 휠 순환), Q로 바닥에 버리기. 무기는 **해당 핫바 슬롯을 선택 중일 때만** 손에 듦(빈 슬롯·소모품 등 다른 아이템 선택 시 즉시 비장착). 선택 슬롯에 무기를 주우면 자동 장착, 버리거나 파손되면 자동 해제. **버린 아이템은 남은 내구도 보존**(재획득 시 이어짐). **재료·귀중품(MATERIAL/KEY/VALUABLE)은 핫바 미등록**, 하단 "재료:" 줄에 집계 표시 |
| ● 아이템 체계 | 타입 6종: WEAPON / FOOD / MEDICAL / MATERIAL / KEY / VALUABLE. 희귀도 5단계 색상(회·녹·청·보라·주황). **아이템 12종**, LootTable 2종(med_cabinet, trash_common). 갈증 계열: 생수(45) / 탄산음료(35) / 주류(25) — trash_common에서 모두 드롭, 생수는 med_cabinet에도 등장 |
| ● 메타 데이터 | GameState 오토로드: 스크랩 / 퍼크 해제 / 최고 추출 가치. `user://savegame.cfg` 저장·로드 |
| ● 소음 시스템 | NoiseSystem 오토로드: `emit_noise(pos, radius, priority)` → 등록된 리스너 좀비 investigate |
| ○ 절차 맵 | **무한 절차 월드 완료**: 플레이어 추종 청크 스트리밍(반경 2칸), 좌표 해시 결정론 도로 그래프, 블록 패턴 5종, 런마다 다른 시드. 잔여: 구역 3단계 난이도, 외곽 추출존 |
| ○ 제작 | 레시피 5~8개(밴디지 등) — 목록 미확정 |
| ○ 추출·허브 | 추출 확정 보상, 허브 퍼크 12~15개 — UI 미구현 |

## 4. 공통 UX 원칙

- 카메라: 피치 -86° 고정 탑다운, 플레이어 lerp 추종, 휠 줌 6~13m, FOV 45.
- 입력 맵(project.godot 등록): WASD 이동 / 좌클릭 공격 / 우클릭 조준 / E 수색·소모품 섭취(수색 우선) / Tab 인벤 / Shift 질주 / R 리로드 / Space 구르기 / 휠 줌·퀵슬롯 순환.
- 조준 시 마우스 방향으로 캐릭터 회전(lerp), 평시엔 이동 방향. 후퇴 시 속도 65%.
- **행동 막대(수색/섭취 진행바)는 화면 고정이 아니라 캐릭터 머리 위(2.15m)에 표시** — 카메라 프로젝션으로 매 프레임 추적, 홀드 해제 시 숨김.
- 해상도 1920×1080, stretch = canvas_items / aspect expand, MSAA 2x.
- 물리 레이어: 1 world / 2 player / 3 zombie / 4 interactable / 5 projectile.
- Kenney Blocky Characters 애님 클립(idle/walk/sprint/holding-*/attack-melee-right/die) 재사용.

## 5. 확인 필요

- 화기 도입 시점과 에셋 방식(커스텀 저폴리 vs Blaster Kit 리텍스처) — M6 이후 검토.
- 제작 레시피 5~8개 구성 확정.
- Tab 인벤토리 전체 UI와 퀵슬롯 HUD의 정보 구조(내구도 표시 위치 등) 확정.
- 좀비 3종 변형(일반·빠름·탱크)의 스탯 차등 수치 확정.
