# 요구사항 요약

원본 계획: [PLAN.md](PLAN.md) (v1.0, 2026-08-22 승인). 이 문서는 현재 합의된 요구사항의 요약본이다.

## 1. 제품 목표

- 탑다운 3D 좀비 아포칼립스 **파밍 로그라이크** "DEAD BLOCK"(가칭).
- 전투보다 "무엇을 털고 어떻게 나올 것인가"의 판단(리스크/리턴)이 중심인 파밍 루프를 제공한다.
- 죽으면 런 수집물은 소실, 메타 재화만 보존되는 반복 동기를 만든다.

## 2. 사용자

- 로그라이크·서바이벌 장르를 즐기는 PC 단일 플레이 유저.
- 멀티플레이·보스·날씨는 범위에서 보류(파밍 루프 검증이 1차 관문).

## 3. 주요 기능

| 기능 | 요약 |
|---|---|
| 핵심 루프 | 진입 → 파밍 → 좀비 조우·회피·전투 → 인벤 관리 → 탈출 → 메타 성장 → 재도전 |
| 파밍 | `Interactable` 컨테이너 홀드 E 수색(진행바 1.5~2.5초), 완료 시 NoiseEvent(반경 8m). LootTable 기반, 컨테이너 런당 1회 |
| 좀비 AI | FSM(IDLE→WANDER→CHASE→ATTACK), 시야+소음 인지, 일반·빠름·탱크 3종, 동시 활성 50마리 목표 |
| 전투 | 근접 중심(Area3D 스윙), 무기 내구도, 피격 시 넉백+플래시 |
| 맵 생성 | 청크 기반 절차 배치, 구역 3단계 난이도(주택가→상업가→병원), 외곽 추출존 차량 |
| 인벤토리 | 무게제 슬롯 20칸 + 퀵슬롯 4개, 제작 레시피 5~8개 |
| 생존/메타 | HP·허기·스테미나 / 허브 씬에서 스크랩으로 퍼크 12~15개 |

## 4. 공통 UX 원칙

- 카메라: 피치 -86° 고정 탑다운, 휠 줌 6~13m, 플레이어 lerp 추종.
- 입력 맵: WASD 이동 / 마우스 조준·공격 / E 수색 / Tab 인벤 / Shift 달리기 / R 리로드 / Space 구르기 / 휠 줌.
- 해상도 1920×1080, stretch = canvas_items.
- 바닥 아이템은 Sprite3D 빌보드 아이콘으로 식별성 확보.
- 물리 레이어: 1 world / 2 player / 3 zombie / 4 interactable / 5 projectile.

## 5. 확인 필요

- 화기 도입 시점과 에셋 방식(커스텀 저폴리 vs Blaster Kit 리텍스처) — M6 이후 검토 예정.
- 제작 레시피 5~8개 구성 확정.
