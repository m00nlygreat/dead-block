# 요구사항 요약

원본 계획: [PLAN.md](PLAN.md) (v1.0, 2026-08-22 승인). 이 문서는 **현재 구현 기준 합의 사항**의 요약본이다. 2026-09-01 코드 기준으로 동기화함.

## 1. 제품 목표

- 탑다운 3D 좀비 아포칼립스 **파밍 로그라이크** "DEAD BLOCK" (v0.1.0).
- 전투보다 "무엇을 털고 어떻게 나올 것인가"의 판단(리스크/리턴)이 중심인 파밍 루프를 제공한다.
- 죽으면 런 수집물은 소실, 메타 재화(스크랩)만 보존되는 반복 동기를 만든다.

## 2. 사용자

- 로그라이크·서바이벌 장르를 즐기는 PC 단일 플레이 유저.
- 멀티플레이·보스·날씨는 범위에서 보류(파밍 루프 검증이 1차 관문).

## 3. 주요 기능 (구현 수준: ●완료 / ○예정)

| 기능 | 현재 합의 사항 |
|---|---|
| ● 핵심 루프 | 진입(main_menu→stage1) → 파밍 → 좀비 조우·전투 → 인벤 관리 → (M4~)탈출 → 메타 성장 |
| ● 파밍 | `Interactable` 홀드 E 수색(기본 `search_time` 1.0초, 이동·섭취 중 취소), 완료 시 소음 반경 8m(priority 1). **수색 대상은 차량 트렁크·집 전부**(런당 1회, 초과 수집분은 바닥 드롭 — 집은 건물 내부가 아닌 수색한 플레이어 주변에 드롭). **수색 여부는 텍스트 라벨 대신 오브젝트 색상으로 표시** — 수색 완료된 차량/집은 조명의 영향을 받지 않는(unshaded) **어두운 회색 단색**으로 전환(어떤 조명에서도 일정, 원본과 명확히 구분). **컨테이너 공용 빈 확률 `empty_chance`**: 차량 0.5 / 집 0.7(수색 가능 컨테이너 증가분 조절 — 블록당 기대 룻 ≈2.5 유지). **줍기 판정은 수색보다 우선** — 수색 범위와 아이템 드롭이 겹치면 아이템부터 획득 |
| ● 좀비 AI | FSM(IDLE/WANDER/CHASE/ATTACK/DEAD), 인지 주기 0.2초. 시야 10m·FOV 100° + 2m 이내 무조건 인지, LOS 레이캐스트(world 레이어). 어그로 해제 = 1.6×시야. 공격 선딜 0.25초 / 쿨 1.1초 / 피해 10. **호드 단위 스폰**: 모든 스폰은 1~4마리 호드(가중치 [45,52,2,1] → 1~2마리 약 97%, 3~4마리 극히 희소 약 3%), 같은 지점 반경 2.2m 내 군집 스폰. 간격 4초 / 플레이어 반경 14~24m / 동시 상한 60마리. **원거리 디스폰**: 플레이어 40m 초과 좀비는 보상 없이 매 스폰 사이클 제거, 상한 도달 시 가장 먼 좀비를 비워 교체 스폰. **격파 시 코인 1개 드롭**, 접촉 수집 → 별도 점수 누적(HUD 좌상단, 런 시작/재시작 시 초기화). **안 주운 코인은 40m 밖 이탈 시 놓친 코인 수(`GameState.missed_coins`)로 기록 후 제거** |
| ● 근접 전투 | 맨손: 피해 25 / 사거리 1.8m / 90° / 밀려남·경직 없음. **근접 무기는 야구배트·부억칼·날붙이 3종**. 야구배트(ItemData 스탯: 30 dmg / 2.6m / 100° / 2타점 / 내구 40 / 쿨 0.75 / 밀려남 3.0 / 경직 0.25초, 모델 표시 배율 1.5×). **부억칼**(60 dmg = 좀비 1방 / 1.8m 주먹과 동일 / 90° / 1타점 / 내구 12 / 쿨 0.6 / 밀려남 없음 / 경직 0.25초, 모델 표시 배율 3.0×). **날붙이**(안전가옥 제작품 — 부억칼과 동일 스펙, 내구만 7). 배트 전용 강화 업그레이드는 **배트 장착 중에만** 적용. 내구도는 명중 시에만 소모. 공격 시 소음 반경 5m |
| ● 원거리 전투 | **9mm 권총**: 좌클릭+우클릭(조준) 동시 홀드 시 발사(연사, 좌·우 각각 홀드 유지 필요 — 클릭 즉발 아님). 대미지 30 / 사거리 30m / **장탄 14(`durability` 사용, 빈 탄창이어도 파손되지 않고 0발 유지)** / 쿨 0.35초. **10% 확률 헤드샷 즉사**. 투사체(레이 스윕 40m/s, 마우스 방향 수평 발사, 발광 구체 총알 + 수평 궤적 잔상 + 미광, 벽 충돌 소멸). 발사 시 소음 반경 5m. **습득 규칙**: 이미 권총 보유 중이면 새 슬롯 없이 **장탄수를 최대 14로 보충**, 첫 습득이면 핫바에 등록·자동 장착. 발사 모션 없음(무기 흔들림 애님 미사용) |
| ● 생존 스탯 | HP 100 / 스테미나 100 / **허기+갈증 2종**(감소 속도: 허기 300초, 갈증 210초). 허기 0 시 스테미나 회복 절반, 허기·갈증 0 지속 시 2초마다 HP -2. 피격 무적 0.45초 + 넉백 |
| ● 소모품 섭취 | E키 홀드로 섭취. **시작 시에만** 수색 우선(수색 대상 근처에선 시작 불가). 일단 시작하면 수색 범위에 들어가도 끝까지 완료. `consume_time` 경과 후 효과 적용. 섭취 중 이동 속도 55% 감소, 조준·질주 불가. **모든 소모품은 1회용**(사용 시 1개 제거, 남은 개수만큼 반복 가능) |
| ● 인벤토리 | 슬롯 20칸 + **무게 상한 40**, 스택형(`max_stack`). 퀵슬롯 **8칸**(1~8 키 / 휠 순환), Q로 바닥에 버리기. 무기는 **해당 핫바 슬롯을 선택 중일 때만** 손에 듦(빈 슬롯·소모품 등 다른 아이템 선택 시 즉시 비장착). 선택 슬롯에 무기를 주우면 자동 장착, 버리거나 파손되면 자동 해제. **버린 아이템은 남은 내구도 보존**(재획득 시 이어짐). **재료·귀중품(MATERIAL/KEY/VALUABLE)은 핫바 미등록**, 하단 "재료:" 줄에 집계 표시 |
| ● 아이템 체계 | 타입 6종: WEAPON / FOOD / MEDICAL / MATERIAL / KEY / VALUABLE. 희귀도 5단계 색상(회·녹·청·보라·주황). **아이템 11종**(무기 4종: 야구배트·부억칼·날붙이·9mm 권총), LootTable 1종(trash_common — **차량 트렁크·집 공용**). **룻 스폰 비중(제작 재료 우대)**: 제작 재료(고철 45·천 50) 합 61.7% / 소모품(식·음료·생수) 30.5% / 무기(배트 4·부억칼 3·권총 5) 7.8% — 제작 템이 잘 나오고 소모품·무기는 상대적으로 희소. 갈증 계열: 생수(45) / 탄산음료(35) / 주류(25) — trash_common에서 모두 드롭. **콘텐츠 추가는 사용자 승인 필수**(AGENTS.md 규칙) |
| ● 메타 데이터 | GameState 오토로드: 스크랩 / 퍼크 해제 / 최고 추출 가치. `user://savegame.cfg` 저장·로드 |
| ● 처치·안전가옥 성장 | **경험치/레벨 개념 없음, 코인 구매제**. "안전가옥"은 물리 건물이 아니라 **업그레이드 화면 자체**다. 좀비 격파마다 처치 수 +1, **10처치 달성 약 1초 후 안전가옥 화면 진입**(게임 일시정지 — 지연은 마지막 격파 좀비의 코인 회수 시간 확보용이며, 지연 중 리셋·사망 시 개방 취소). **개방 시 플레이어 반경 8m 내 좀비를 원형으로 밀어내는 파동**(세기 12, 사망 좀비·반경 밖 제외). **화면 3분할**: 좌측 업그레이드(카드 3장 세로 배치, 폭 480px·폰트 16), 중앙 구매(붕대·생수 각 5코인, 보유 수량 표시, 인벤 불가 시 환불), 우측 제작(날붙이 = 고철 조각×2+천 조각×1 / 붕대 = 천 조각×2, 재료 부족 시 비활성). 각 업그레이드 카드에 **코인 가격 표시**, 클릭 시 차감·즉시 적용, **카드 3장은 진입 시 추첨 후 그 방문에서 고정**이며 **구매한 칸은 빈 슬롯**으로 남음(재추첨·같은 카드 반복 구매 없음 — 카드당 방문당 1회, 다음 방문에 새 3장), 코인 부족 카드는 비활성. [떠나기(ESC)]로 닫으면 게임 재개 — 다음 10처치마다 다시 열림. 가격 = `cost × (보유 단계+1)`(UpgradeData.cost: 8~30). 업그레이드 10종(`resources/upgrades/*.tres`): 최대 HP+20(즉시 회복)/이속+8%/피해+15%/쿨다운−8%/코인 자석 반경+30%/스태미너 회복+20%(각 5단계), 배트 사거리+0.4m(3단계)·타점+1·밀려남+50%(각 2단계, 배트 장착 중에만), 재활용(격파 시 10% 확률 스크랩+1, 메타 재화, 1회). 사망/재시작 시 UpgradeManager.reset_run으로 전부 초기화. HUD 상단 중앙 "처치 N · 다음 안전가옥 M킬" 표시 |
| ● 소음 시스템 | NoiseSystem 오토로드: `emit_noise(pos, radius, priority)` → 등록된 리스너 좀비 investigate |
| ○ 절차 맵 | **무한 절차 월드 완료**: 플레이어 추종 청크 스트리밍(반경 2칸), 좌표 해시 결정론 도로 그래프, 블록 패턴 5종, 런마다 다른 시드. **털린 구조물**(이미 수색 완료 상태의 장식용 집·차량 — 그레이스케일·수색 불가, 룻 없음)을 전 패턴에 배치(털린 집 0~4 + 털린 차 1~5/블록)해 탐색 필드를 빽빽하게 채움. 털린 구조물은 무한 월드 스트리밍의 일부로 로드/언로드된다. 잔여: 구역 3단계 난이도, 외곽 추출존 |
| ● 제작 | 안전가옥 우측에서 재료 제작: **날붙이**(고철 조각×2 + 천 조각×1)·**붕대**(천 조각×2). 재료 부족 시 버튼 비활성, 결과를 인벤에 넣지 못하면 재료 환불. PLAN상 레시피 5~8개 중 현재 2종 확정 |
| ○ 추출·허브 | 추출 확정 보상, 허브 퍼크 12~15개 — UI 미구현 |

## 4. 공통 UX 원칙

- 카메라: 피치 -86° 고정 탑다운, 플레이어 lerp 추종, 휠 줌 6~13m, FOV 45.
- 입력 맵(project.godot 등록): WASD 이동 / 좌클릭 공격 / 우클릭 조준 / E 수색·소모품 섭취(수색 우선) / Tab 인벤 / Shift 질주 / R 리로드 / Space 구르기 / 휠 줌·퀵슬롯 순환.
- 조준 시 마우스 방향으로 캐릭터 회전(lerp), 평시엔 이동 방향. 후퇴 시 속도 65%.
- **행동 막대(수색/섭취 진행바)는 화면 고정이 아니라 캐릭터 머리 위(2.15m)에 표시** — 카메라 프로젝션으로 매 프레임 추적, 홀드 해제 시 숨김.
- 해상도 1920×1080, stretch = canvas_items / aspect expand, MSAA 2x.
- 물리 레이어: 1 world / 2 player / 3 zombie / 4 interactable / 5 projectile.
- Kenney Blocky Characters 애님 클립(idle/walk/sprint/holding-*/attack-melee-right/die) 재사용.

## 5. 확인 필요

- 화기 도입 시점과 에셋 방식(커스텀 저폴리 vs Blaster Kit 리텍스처) — M6 이후 검토.
- 제작 레시피 확대 구성 확정(현재 2종: 날붙이·붕대 — 목표 5~8개).
- Tab 인벤토리 전체 UI와 퀵슬롯 HUD의 정보 구조(내구도 표시 위치 등) 확정.
- 좀비 3종 변형(일반·빠름·탱크)의 스탯 차등 수치 확정.
